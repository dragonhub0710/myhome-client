# Myhome
A modern real estate platform that empowers users to create and estimate the cost of their home projects. Built with Next.js, TypeScript, and Supabase, Myhome streamlines the process of planning, customizing, and pricing real estate projects.

## Features
- Project Creation: Users can start a new project and answer guided questions about their requirements.
- Dynamic Product Suggestions: Based on user responses, relevant products and services are automatically added to the project.
- Cost Estimation: Instantly calculate the approximate total price for the entire project, helping users plan and budget effectively.
- Modern Tech Stack: Built with Next.js for fast, scalable web experiences, TypeScript for robust type safety, and Supabase for seamless backend and database management.
